## Как запустить
Для запуска финальной версии приложении (шардинг + репликация + кеш), 
нужно перейти в папку sharding-repl-cache и запустить mongodb и приложение:

```shell
cd sharding-repl-cache
docker compose up -d
```
Для настройки шардирования и репликации, а также заполнения mongodb данными, 
из этой же директории (sharding-repl-cache) нужно запустить скрипт:

```shell
./scripts/mongo-init.sh
```
В итоге в монге будет создана бд somedb и коллекция helloDoc с 1000 документами

## Как проверить

### Если вы запускаете проект на локальной машине

Откройте в браузере http://localhost:8080

### Если вы запускаете проект на предоставленной виртуальной машине

Узнать белый ip виртуальной машины

```shell
curl --silent http://ifconfig.me
```

Откройте в браузере http://<ip виртуальной машины>:8080

## Проверка кеша
Для проверки скорости получения данных за счет добавления кеша,
можно выполнить скрипт, который измеряет скорость ответа делая 5 запросов к приложению:
```shell
./sharding-repl-cache/scripts/time.sh
```

В ответе будет информация в виде: 
Запрос 1: 8.92 мс
